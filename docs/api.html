API SMM Reseller

Shine Shop · dokumentasi endpoint resmi
Login Home

📌 Ringkasan

API ini memungkinkan reseller membuat order SMM melalui Shine Shop. Order memotong saldo akun pemilik API key. Harga di endpoint sudah harga jual final.

Base URL
https://shinedomain.my.id/api/smm
🔑 API key dibuat di Home → API Key SMM (setelah login). Format: sk_live_…

📚 Daftar isi

1. Autentikasi 2. Services — daftar layanan 3. Add — buat order 4. Status — cek order 5. Balance — cek saldo 6. Refill 7. Kode error 8. Contoh cURL

🔐 Autentikasi

Kirim API key dengan salah satu cara:

  • Header: x-api-key: sk_live_xxx
  • Header: Authorization: Bearer sk_live_xxx
  • Query / body: key / api_key / apikey

Method: GET atau POST (JSON / form). Parameter action wajib (kecuali default services).

GET Services

Daftar layanan + harga (sudah dikurangi 3%) + kategori.

GET /api/smm?action=services&key=sk_live_xxx

Response (cuplikan)

{
  "status": true,
  "count": 1200,
  "data": [
    {
      "service": 1234,
      "name": "Instagram Followers",
      "category": "Instagram",
      "rate": 10800,
      "min": 100,
      "max": 100000,
      "refill": true
    }
  ]
}

rate = harga per 1000 (IDR). Charge order ≈ (rate × quantity) / 1000.

POST Add (buat order)

Parameter wajib: service, target, quantity.

POST /api/smm
Content-Type: application/json
x-api-key: sk_live_xxx

{
  "action": "add",
  "service": 1234,
  "target": "https://instagram.com/username",
  "quantity": 1000,
  "custom_comments": ""
}

Response sukses

{
  "status": true,
  "order": 1107,
  "charge": 10800,
  "currency": "IDR",
  "balance": 89000,
  "msg": "Order #1107 berhasil"
}
Charge ≈ (rate × quantity) / 1000, dibulatkan ke atas. Saldo tidak cukup → HTTP 402.

GET Status

GET /api/smm?action=status&order=1107&key=sk_live_xxx

Response

{
  "status": true,
  "order": "1107",
  "data": {
    "status": "Completed",
    "start_count": 1200,
    "remains": 0,
    "charge": 10000,
    "currency": "IDR"
  }
}

GET Balance

GET /api/smm?action=balance&key=sk_live_xxx
{
  "status": true,
  "balance": 150000,
  "currency": "IDR",
  "email": "user@gmail.com"
}

POST Refill

Request refill ke provider (jika layanan support refill).

POST /api/smm
Content-Type: application/json
x-api-key: sk_live_xxx

{ "action": "refill", "order": 1107 }

⚠️ Error umum

HTTPArti
400Parameter kurang / action tidak dikenal
401API key invalid / nonaktif
402Saldo tidak cukup
502Provider menolak / error upstream
500ENV server belum lengkap

Body error biasanya: {"status":false,"error":"…"}

🧪 Contoh cURL

Services

curl -G "https://shinedomain.my.id/api/smm" \
  -d "action=services" \
  -d "key=sk_live_YOUR_KEY"

Add order

curl -X POST "https://shinedomain.my.id/api/smm" \
  -H "Content-Type: application/json" \
  -H "x-api-key: sk_live_YOUR_KEY" \
  -d '{"action":"add","service":1234,"target":"@user","quantity":1000}'

Status

curl -G "https://shinedomain.my.id/api/smm" \
  -d "action=status" \
  -d "order=1107" \
  -d "key=sk_live_YOUR_KEY"

Balance

curl -G "https://shinedomain.my.id/api/smm" \
  -d "action=balance" \
  -d "key=sk_live_YOUR_KEY"

💡 Tips reseller

  • Simpan API key di server/bot — jangan di frontend publik.
  • Generate key baru di Home → API Key SMM; revoke jika bocor.
  • Isi saldo lewat deposit di aplikasi Shine Shop.
  • Health check (tanpa key): /api/smm?action=health
